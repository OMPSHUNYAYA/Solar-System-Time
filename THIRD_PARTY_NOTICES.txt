2. NASA/JPL planetary constants and services

The reference resolver contains a small set of published numerical orbital-element constants for the Earth-Moon barycenter (JPL "EM Bary"), Uranus, and Neptune derived from NASA/JPL Solar System Dynamics approximate planetary-position material. The EM-Bary values are used as the compact observer-orbit proxy. These numerical values are retained as minimum factual scientific inputs required to reproduce the declared low-complexity model.

The interactive Solar System Clock contains the corresponding low-precision Table-1-family orbital-element values for Mercury through Neptune. Its displayed "Earth" label is a visualization label; the underlying low-precision Earth-orbit row follows the JPL EM-Bary approximation used by that element family.

NASA/JPL Horizons was used in earlier declared project verification for a separate precision-ephemeris replication stage. Horizons payloads and bulk JPL ephemeris data are not distributed in this package.

The project does not claim ownership of NASA/JPL source material, services, documentation, ephemerides, or underlying astronomical facts.

9. Astrometric-coordinate interpretation

The active J2000 Uranus/Neptune resolver applies retarded planetary light-time.
Stellar aberration is not applied to this astrometric-coordinate lane. JPL
Horizons documentation distinguishes astrometric from apparent coordinates.
