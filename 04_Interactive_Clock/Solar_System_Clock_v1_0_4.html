Planetary configuration can be viewed as a structural clock state. Displayed positions use a low-precision approximate orbital model intended for visualization, not precision ephemerides.

Solar System Time treats a declared planetary configuration as a structural time state. The forward direction resolves an epoch into a Solar-System state; the inverse direction searches a declared historical interval for the epoch most consistent with an observed state.

Demonstration default: the clock opens at the current epoch and advances at 30 days per second so the changing Solar-System state is immediately visible. Press NOW at any time to return to current UTC at 1× real time.
