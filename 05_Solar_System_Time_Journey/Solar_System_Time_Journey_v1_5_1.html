Completed Journey summaries stay only in this browser and do not include route coordinates.
Scientific boundary: SSTJ does not claim that walking, running, cycling, riding or driving changes the planetary clock. Live browser-geolocation ground distance uses WGS84 geodesics over consecutive fixes that pass reported-accuracy and timestamp-freshness gates, followed by accuracy-relative positional-noise and activity-speed qualification; rejected fixes do not add qualified distance and do not bridge to the next qualified fix. Manual Pause stops ground acquisition and prevents a cross-pause segment, while real elapsed time and approximate Earth-rotation/orbit carriage continue. Browser-reported accuracy is summarized as measurement-quality evidence and is not converted into a cumulative distance confidence interval. A bounded fresh-position request may be used after sustained callback silence; it does not bypass accuracy, timestamp, positional-noise, or activity-speed qualification. Solar Splits are project-derived distance milestones interpolated within accepted segments; kilometre/mile choice changes only the declared milestone system and presentation layer, while canonical geometry remains metric. Walk/Run steps remain estimates. Speed, heading, altitude, and altitudeAccuracy may be unavailable on some browsers/devices. Recent Journey history stores only compact local summaries in browser storage and excludes route coordinates. Earth-rotation and Earth-orbit distances are approximate derived quantities. The planetary display is a low-precision model restricted to 1800-2050. The SHA-256 record digest and breadcrumb hash chain provide tamper evidence but do not prove physical presence or browser-location authenticity.

Planetary configuration can be viewed as a structural clock state. Displayed positions use a low-precision approximate orbital model intended for visualization, not precision ephemerides, and are restricted to the declared 1800-2050 element-validity window.

Solar System Time Journey (SSTJ) uses Solar System Time as its planetary structural clock. Journey Mode adds a separate observer/place-time layer: a live route can be recorded alongside the evolving clock without changing the underlying planetary model. The forward direction resolves an epoch into a Solar-System state; the inverse direction searches a declared historical interval for the epoch most consistent with an observed state.

Demonstration default: the clock opens at the current epoch and advances at 30 days per second so the changing Solar-System state is immediately visible. Press NOW at any time to return to current UTC at 1× real time.
