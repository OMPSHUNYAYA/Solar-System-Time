3. WGS84 factual constants

The journey geometry uses the standard WGS84 ellipsoid constants:

semi-major axis = 6378137 m

inverse flattening = 298.257223563

These are factual geodetic constants.

The WGS84 geodesic routines in the application are project-authored implementations of standard Vincenty direct/inverse methodology. No third-party geodesic source code or runtime library is bundled.

Relevant provenance:

National Geospatial-Intelligence Agency (NGA), World Geodetic System 1984 (WGS 84) defining parameters
https://earth-info.nga.mil/

T. Vincenty, "Direct and Inverse Solutions of Geodesics on the Ellipsoid with Application of Nested Equations" (1975). The package cites the standard method only; it does not reproduce third-party source code or substantial publication text.
